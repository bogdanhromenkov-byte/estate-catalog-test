### ШАГ 2: Настройте безопасность (ВАЖНО для production!)

После обновления подключитесь к серверу:

```bash
ssh root@164.92.223.4
```

Отредактируйте .env файл:

```bash
nano /home/estate/estate-catalog/.env
```

Найдите и измените эти строки:

```bash
# Укажите ваш реальный домен Bitrix24
BITRIX24_DOMAIN=https://ваша-компания.bitrix24.ru

# Укажите разрешенные домены для API
ALLOWED_ORIGINS=https://ваша-компания.bitrix24.ru
```

Сохраните (Ctrl+O, Enter, Ctrl+X) и перезапустите:

```bash
supervisorctl restart estate
exit
```

**Почему это важно:**
- Сейчас у вас стоит `*` - разрешены ВСЕ домены (только для разработки!)
- В production нужно указать только ваш Bitrix24, иначе злоумышленники смогут встроить ваш сайт куда угодно
